# Pinned dependencies

Generated by `pip-compile` (pip-tools) from `../pyproject.toml`. Do not hand-edit.

| File | Contents | Used by |
|---|---|---|
| `prod.txt` | core + `voice` extra | Dockerfile |
| `dev.txt` | core + `dev` extra | CI `backend` job, local dev without voice |
| `dev-voice.txt` | core + `dev` + `voice` | CI `backend-voice` job, full local dev |

Install a lockfile, then the app without re-resolving:

    pip install -r requirements/dev.txt && pip install --no-deps -e .

To add or bump a dependency: edit `pyproject.toml`, then from `backend/` run
`scripts/lock.sh` (or `scripts/lock.sh --upgrade` to move everything to the latest allowed
versions), run the test suite, and commit the regenerated files.

The lockfiles were compiled on Python 3.12. The pinned packages ship wheels for Linux and macOS.
